# Python Quiz Game

## 실행 방법
- 저장소 클론: `git clone [본인의 깃허브 주소]`
- 실행: `python main.py`

## 클래스 책임 분리
- `Quiz`: 퀴즈의 질문, 보기, 정답 데이터를 저장하고 정답 여부를 판별하는 데이터 모델 역할.
- `QuizGame`: JSON 파일 입출력, 게임 진행 로직, 점수 관리, 퀴즈 추가 등 전체 시스템을 제어하는 역할.
- 장점: 함수 기반 설계보다 데이터와 로직이 캡슐화되어 유지보수와 확장이 용이함.

## 데이터 흐름 및 저장 방식
- 로직 분리: 입력 처리(main), 게임 진행(play), 저장 로직(save_data)으로 분리.
- JSON 사용 이유: 텍스트 파일보다 리스트, 딕셔너리 등 중첩된 구조를 직관적이고 가독성 좋게 저장할 수 있기 때문.
- 흐름: 프로그램 시작 시 `state.json` 로드 -> 게임 중 데이터 업데이트 -> 최고점수 갱신 또는 퀴즈 추가 시 `state.json` 저장.
- state.json 구조: `{"quizzes": [{"question": "...", "choices": [], "answer": 1}], "high_score": 0}`

## 예외 처리 및 안전 종료
- `FileNotFoundError`: 파일이 없을 경우 예외를 잡아내어 기본 퀴즈 5개를 자동 생성하도록 처리.
- `ValueError`: 숫자 입력란에 문자를 넣었을 때 프로그램이 종료되지 않도록 처리.
- `SIGINT`: `signal` 모듈을 사용해 Ctrl+C 입력 시 안전하게 종료되도록 구현.

## 성능 및 확장성 분석
- 문제 수가 1000개 이상으로 증가할 경우, JSON 전체를 메모리에 올리는 방식은 성능 저하가 발생할 수 있으므로 SQLite 같은 DB 도입이 필요함.
- 요구사항 변경 시 수정 위치: 점수 계산 방식 변경 시 `QuizGame.play()` 수정, 퀴즈 구조 변경 시 `Quiz` 클래스 수정.
- 백업 전략: 정기적으로 `state.json`을 `state_backup.json`으로 복사하는 스크립트 추가 고려.
