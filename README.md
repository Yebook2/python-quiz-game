# 파이썬 퀴즈 게임 프로젝트

사용자가 직접 퀴즈를 풀고, 새로운 퀴즈를 추가할 수 있는 콘솔 기반의 파이썬 퀴즈 게임입니다.
최고 점수와 추가된 퀴즈 목록은 JSON 파일로 안전하게 저장 및 관리됩니다.

## 1. 클래스 설계 및 책임

본 프로젝트는 객체 지향 프로그래밍(OOP) 원칙에 따라 두 개의 주요 클래스로 분리하여 설계되었습니다.

### Quiz 클래스
단일 퀴즈 데이터의 상태와 검증 로직을 담당합니다.
* `__init__`: 질문, 보기, 정답을 초기화합니다.
* `is_correct(user_answer)`: 사용자의 입력값과 정답이 일치하는지 검증합니다.
* `to_dict()`: 데이터를 JSON 형식으로 저장하기 위해 딕셔너리 형태로 변환합니다.

### QuizGame 클래스
게임의 전반적인 흐름, 파일 입출력, 메뉴 시스템을 관리합니다.
* `load_data() / save_data()`: state.json 파일과 데이터를 주고받으며 상태를 유지합니다.
* `play()`: 퀴즈 진행, 점수 계산, 최고 점수 갱신 로직을 처리합니다.
* `add_quiz()`: 사용자로부터 입력을 받아 새로운 퀴즈를 리스트에 추가합니다.
* `show_quizzes()`: 현재 등록된 모든 퀴즈의 목록을 출력합니다.

## 2. 입력 처리 흐름 및 예외 처리

사용자 입력 시 발생할 수 있는 오류를 방지하기 위해 단계별 검증 로직을 구현했습니다.

1. **자료형 검증**: `try-except ValueError`를 사용하여 문자열이나 빈칸 입력 시 프로그램이 종료되지 않고 재입력을 요구합니다.
2. **범위 검증**: `if 1 <= user_input <= 4:` 조건문을 통해 1~4 사이의 유효한 번호만 입력받도록 제한합니다.
3. **무한 루프 방어**: 올바른 입력이 들어올 때까지 `while True` 루프를 유지하며, 정상 입력 시 `break`로 탈출합니다.

## 3. 데이터 안정성 및 예외 처리 전략

프로그램 종료 및 예기치 않은 상황에서도 데이터가 손실되지 않도록 설계했습니다.

* **정상 종료 시 저장**: 메뉴에서 '4. 종료'를 선택하면 명시적으로 `save_data()`를 호출하여 데이터를 안전하게 저장합니다.
* **강제 종료(SIGINT) 방어**: `Ctrl+C` 입력 시 `signal_handler`가 작동하여, 즉시 종료되지 않고 현재 상태를 저장한 뒤 안전하게 종료됩니다.
* **파일 I/O 예외 처리**: `save_data()` 실행 시 디스크 용량 부족이나 권한 문제로 발생할 수 있는 `IOError`를 `try-except`로 잡아내어 프로그램 크래시를 방지합니다.
* **동시 실행 대비 파일 잠금 전략 (향후 확장성)**: 현재는 단일 사용자 환경을 가정하여 작성되었으나, 다중 실행 환경에서는 파일 쓰기 충돌을 방지하기 위해 `fcntl` (Linux) 또는 `msvcrt` (Windows) 라이브러리를 활용한 File Lock(파일 잠금) 메커니즘을 도입할 수 있도록 구조화되어 있습니다.
